# 超长文档智能判定方案

## 1. 问题分析

根据用户提供的数据，以文件大小作为超长文档的判定标准并不准确：

| 文档 | 页数 | 大小 | 特点 |
|------|------|------|------|
| AI_Engineering.epub | 900+ | 31M | 纯文本为主 |
| agentic-design-patterns-en.epub | 400+ | 3M-6M | 纯文本为主 |
| Hands-On_Large_Language_Models.epub | 598 | 23M | 图片较多 |

**问题**：
- 文件大小与页数不是线性关系
- 图片内容会显著增加文件大小
- 纯文本的大文档可能体积很小
- 翻译处理时间主要取决于页数和内容复杂度

## 2. 新的判定方案

### 2.1 多维度判定指标

| 指标 | 权重 | 判定标准 |
|------|------|----------|
| **页数** | 60% | 主要判定依据 |
| **文件类型** | 20% | 不同格式处理复杂度不同 |
| **内容类型** | 20% | 文本 vs 图片占比 |

### 2.2 具体判定标准

#### 页数阈值

| 页数范围 | 判定结果 |
|----------|----------|
| ≤ 15 页 | 小型文档 |
| 16-50 页 | 中型文档 |
| 51-150 页 | 大型文档 |
| > 150 页 | 超长文档 |

#### 文件类型权重

| 文件类型 | 复杂度系数 |
|----------|------------|
| TXT | 1.0 |
| MD | 1.1 |
| EPUB | 1.2 |
| DOCX | 1.3 |
| PDF (文本) | 1.5 |
| PDF (扫描) | 2.0 |

#### 内容类型调整

| 内容类型 | 调整系数 |
|----------|----------|
| 纯文本 | 1.0 |
| 少量图片 (<10%) | 1.2 |
| 中等图片 (10-30%) | 1.5 |
| 大量图片 (>30%) | 1.8 |

### 2.3 综合判定算法

**步骤 1**: 提取文档页数
**步骤 2**: 识别文件类型
**步骤 3**: 分析内容类型（图片占比）
**步骤 4**: 计算综合复杂度得分
**步骤 5**: 根据得分判定文档类型

**综合复杂度得分 = 页数 × 文件类型系数 × 内容类型系数**

| 综合得分 | 判定结果 |
|----------|----------|
| ≤ 15 | 小型文档 |
| 16-50 | 中型文档 |
| 51-150 | 大型文档 |
| > 150 | 超长文档 |

## 3. 智能拆分策略调整

### 3.1 基于综合复杂度的拆分阈值

| 文档类型 | 页数范围 | 拆分策略 |
|----------|----------|----------|
| 小型文档 | ≤ 15 页 | 不拆分，直接处理 |
| 中型文档 | 16-50 页 | 按章节拆分（如果有） |
| 大型文档 | 51-150 页 | 强制按章节/逻辑拆分 |
| 超长文档 | > 150 页 | 智能多策略拆分 + 并行处理 |

### 3.2 拆分大小建议

| 文档类型 | 建议拆分大小 |
|----------|--------------|
| 纯文本 | 15-30 页/块 |
| 混合内容 | 10-20 页/块 |
| 图片密集 | 5-15 页/块 |

### 3.3 大模型翻译优化

根据实际运行效果，PDF A4 大小的纯文字文档，15页左右大模型翻译效果更好。因此：

- **最佳翻译单元**：15页以内的文档块
- **强制拆分点**：超过15页的文档自动拆分
- **上下文保持**：拆分时保持章节完整性，确保翻译上下文连贯

## 4. 实施建议

### 4.1 页数提取方法

| 文件格式 | 页数提取方法 |
|----------|--------------|
| PDF | 使用 pdfplumber 或 pypdf 获取页数 |
| EPUB | 使用 ebooklib 解析章节和页数 |
| DOCX | 使用 python-docx 获取段落和页数估算 |
| MD | 根据内容长度估算页数（500 字/页） |
| TXT | 根据内容长度估算页数（500 字/页） |
| 直接文本 | 根据内容长度估算页数（500 字/页） |

### 4.2 内容类型分析

| 文件格式 | 内容类型分析方法 |
|----------|------------------|
| PDF | 分析页面元素，统计图片数量 |
| EPUB | 解析 HTML 内容，统计图片标签 |
| DOCX | 使用 python-docx 统计图片数量 |
| MD | 统计图片标记数量 |
| TXT | 默认为纯文本 |
| 直接文本 | 默认为纯文本 |

### 4.3 性能优化

- **缓存机制**：缓存文档分析结果，避免重复分析
- **并行分析**：同时分析多个文档的页数和内容类型
- **增量分析**：对于超大文档，先分析前 10% 内容估算整体复杂度
- **自适应调整**：根据实际处理时间调整拆分策略

### 4.4 TXT 和直接输入文字的特殊处理

#### 4.4.1 页数估算方法

| 语言类型 | 每页估算字数 | 说明 |
|----------|-------------|------|
| **中文** | 500 字/页 | 中文文字密度较高 |
| **英文** | 250 词/页 | 英文单词长度较长 |
| **混合语言** | 取平均值 | 根据实际比例调整 |

#### 4.4.2 判定流程

1. **计算文字数量**：统计中文字符数或英文单词数
2. **估算页数**：文字数量 ÷ 每页估算字数，结果向上取整
3. **应用判定标准**：使用与其他格式相同的页数阈值

#### 4.4.3 特殊情况处理

- **非常短的文本**（少于 100 字）：视为小型文档，直接处理
- **长文本输入**（超过 7500 字）：自动拆分处理
- **格式复杂的 TXT**：包含大量空行、列表、代码块时，适当增加页数估算

#### 4.4.4 实现示例

```python
def estimate_pages(text, language='auto'):
    """估算文本页数"""
    if language == 'auto':
        # 自动检测语言
        if any('\u4e00' <= c <= '\u9fff' for c in text):
            language = 'zh'
        else:
            language = 'en'
    
    if language == 'zh':
        # 中文：500字/页
        char_count = len([c for c in text if '\u4e00' <= c <= '\u9fff' or c in '，。！？；：""''（）【】'])
        pages = math.ceil(char_count / 500)
    else:
        # 英文：250词/页
        words = text.split()
        word_count = len(words)
        pages = math.ceil(word_count / 250)
    
    return pages

def classify_document(text, language='auto'):
    """分类文档类型"""
    pages = estimate_pages(text, language)
    
    if pages <= 15:
        return '小型文档'
    elif 16 <= pages <= 50:
        return '中型文档'
    elif 51 <= pages <= 150:
        return '大型文档'
    else:
        return '超长文档'
```

### 4.5 Markdown 文件的特殊处理

#### 4.5.1 Markdown 与纯文本的区别

Markdown 文件虽然本质上也是文本文件，但具有以下特殊性：

1. **格式标记**：包含标题（#）、列表（-、*）、代码块（```）等格式标记
2. **代码块**：代码块通常占用较多空间，但实际信息密度较低
3. **图片标记**：`![]()` 格式的图片标记需要特殊处理
4. **链接和引用**：`[]()` 格式的链接和引用标记

#### 4.5.2 页数估算调整

对于 Markdown 文件，需要调整页数估算方法：

1. **去除格式标记**：统计纯文本内容，去除 Markdown 语法标记
2. **代码块处理**：代码块按实际行数计算，但降低信息密度权重
3. **图片标记处理**：图片标记不计入字数，但计入内容复杂度

#### 4.5.3 实现示例

```python
import re

def estimate_markdown_pages(text, language='auto'):
    """估算 Markdown 文件页数"""
    
    # 去除代码块（代码块通常信息密度较低）
    text_without_code = re.sub(r'```[\s\S]*?```', '', text)
    
    # 去除图片标记
    text_without_images = re.sub(r'!\[.*?\]\(.*?\)', '', text_without_code)
    
    # 去除链接标记（保留链接文本）
    text_clean = re.sub(r'\[([^\]]+)\]\([^\)]+\)', r'\1', text_without_images)
    
    # 去除标题标记
    text_clean = re.sub(r'^#+\s+', '', text_clean, flags=re.MULTILINE)
    
    # 去除列表标记
    text_clean = re.sub(r'^[\*\-\+]\s+', '', text_clean, flags=re.MULTILINE)
    
    # 使用纯文本的页数估算方法
    return estimate_pages(text_clean, language)
```

#### 4.5.4 Markdown 文件类型系数

| Markdown 类型 | 复杂度系数 | 说明 |
|---------------|------------|------|
| 纯文本 Markdown | 1.0 | 主要是文本内容，少量格式标记 |
| 技术文档 Markdown | 1.3 | 包含代码块、表格、公式等 |
| 混合内容 Markdown | 1.5 | 包含大量图片、链接、引用等 |
